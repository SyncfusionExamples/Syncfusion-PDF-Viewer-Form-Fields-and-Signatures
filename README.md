# PDF Viewer: Validation and Signing Workflow

## Overview

This Angular sample demonstrates a complete PDF form validation and signing workflow using Syncfusion PDF Viewer (`@syncfusion/ej2-angular-pdfviewer`) without a server component.

### Environment

## Prerequisites

- Node.js 20.x or later
- npm 10.x or later
- Valid Syncfusion license key

## Project Setup

Install the required dependencies:

```bash
npm install
```

## License Configuration

Open `src/main.ts` and replace the placeholder license key:

```ts
import { registerLicense } from '@syncfusion/ej2-base';

registerLicense('YOUR_SYNCFUSION_LICENSE_KEY');
```

## Run the Sample

Start the application:

```bash
npm start
```

Open the application in your browser:

```text
http://localhost:4200
```
